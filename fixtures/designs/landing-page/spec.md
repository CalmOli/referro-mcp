# Landing Page — Design Spec

## Overview

A conversion-focused marketing landing page for a SaaS product.

## Goals

- Communicate the core value proposition in under 5 seconds
- Drive signups through a single primary CTA
- Establish trust with logos, stats, and testimonials

## Sections

### Hero
- Headline: "Ship faster with Referro"
- Subheadline: one sentence on the product benefit
- Primary CTA: "Start free trial"
- Secondary CTA: "Book a demo"

### Features
- Three-column grid: Automation, Collaboration, Analytics
- Feature icon + title + one-line description each

### Pricing
- Three tiers: Starter, Pro, Enterprise
- Monthly/annual toggle
- "Most popular" badge on Pro

### Social proof
- Logos row (6 customer logos)
- 2–3 short testimonials with avatars

## Design tokens

- Primary: #4F46E5 (indigo 600)
- Background: #FFFFFF / #F8FAFC
- Text: #0F172A
- Radius: 8px cards, 999px buttons
- Font: Inter, system-ui fallback

## Breakpoints

- Mobile: < 640px, single column
- Tablet: 640–1024px, two columns
- Desktop: > 1024px, three columns

## Handoff

Provide the engineering team with:

- `landing-hero.png` (1920x1080)
- `landing-features.png` (1440x900)
- Figma file with auto-layout components
